# AI Teaching Tutor

A Python and Streamlit application for learning AI, data science, Docker, FastAPI, and related technologies.

## Local Setup
Create and activate a virtual environment, then install dependencies:

```text
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
